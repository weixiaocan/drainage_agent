## 判断方法

**重要概念定义**：

**Kz的含义**：Kz=最大流量/平均流量，Kz越小表示波动越小。Kz<1.2表示波动很小。

**周期性规律的定义（泵站调控特征）**：
- 一天内出现**至少4个清晰独立的波峰**，波峰之间间隔相近（间隔2-5小时）
- 每个波峰后必须有明显的波谷，呈锯齿状规律涨落
- 波峰分布在整个24小时内，不集中在特定时段
- **重要区分**：
  - 生活污水规律：高峰集中在早上(7-10点)、中午(11-15点)、晚上(18-22点)这3个时段 -> 这是第1类
  - 周期性规律：波峰分散在全天各时段（包括深夜和凌晨），呈规律性锯齿状 -> 这是第2类泵站调控
- 代码提供的峰值数量可能不准确，请根据48个半小时数据自行判断

**平坦曲线的定义（满足任一条件即可）**：
- Kz<1.2，且波动范围（最大值-最小值）/平均值 < 30%
- 48个半小时数据都在平均值的±20%范围内，无明显峰值
- 或流量极低（日均<1 L/s）

**最重要规则：Kz<1.2的点位绝对不能归为第1类！**

**判断顺序（必须严格按顺序）**：
1. **第一步：检查Kz值**
   - 如果Kz<1.2：**只能选择第2类或第3类**，跳到第3步
   - 如果Kz>=1.2：继续第2步
2. **第二步（Kz>=1.2时）**：
   - **先检查是否符合第1类条件**
   - 如果符合第1类 -> 第1类（结束判断）
   - 如果不符合第1类 -> 检查是否有周期性规律（一天内有至少4个间隔相近的波峰）
   - 有周期性规律 -> 第2类泵站调控
   - 无周期性规律 -> 第2类（根据特征描述原因）
3. **第三步（Kz<1.2时）**：
   - 检查48个半小时数据是否有清晰的周期性规律（波峰波谷差异>20%）
   - 有周期性规律 -> 第2类泵站调控
   - 无周期性规律 -> 第3类曲线平坦

**第3类：曲线平坦/异常**：
- Kz<1.2，且没有周期性规律
- 或流量极低（日均<1 L/s）

**第1类：符合典型生活用水排放规律**：
- 前提：Kz>=1.2
- 条件：查看48个半小时数据，满足以下所有条件：
  1. 夜间(0-7点)流量整体最低（对比其他时段平均值）
  2. 晚上(18-24点)有明显高峰时段（峰值>日均*1.15，或时段平均流量>夜间平均*1.5）
  3. 早上(7-10点)或中午(11-15点)有高峰（峰值>日均即可，不要求突出，有就行）
- 注意：早午高峰不突出但只要有就算符合条件
- 如果夜间流量最低但占比偏高(>15%)，描述中指出"夜间流量偏高"，但仍归为第1类
- 典型特征：夜间流量低->白天逐渐升高->晚上明显高峰->夜间逐渐降低

**第2类：不符合典型生活用水排放规律**：
- Kz<1.2但有清晰周期性规律的 -> 疑似泵站调控（需满足周期性规律定义）
- Kz>=1.2但不符合第1类条件的，根据具体特征判断：
  - 有清晰周期性规律（一天内有多个间隔相近的波峰，波峰波谷差异>25%）-> 疑似泵站调控
  - 间歇性脉冲式排放（大部分时间为0，短暂时段有高峰）-> 疑似工业排水
  - 昼高夜低且夜间流量极低（<10%）-> 疑似公建排水
  - 其他不符合第1类的情况 -> 仅描述曲线特征，不猜测原因
