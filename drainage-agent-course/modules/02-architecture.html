架构分层：谁负责什么

这一页帮你把“项目很散”讲成“职责清晰的分层系统”。

像一栋楼：每层只管自己的事

这个项目的关键不是用了多少库，而是分层边界清楚。面试里可以先画这棵 架构图。

app/CLI 和 Web 启动入口
web/FastAPI 页面、聊天、上传、下载
agent/Pydantic AI Agent、工具注册、依赖、会话状态
analysis/领域算法：降雨、RDII、风险、排污规律、报告
resources/演示数据和 DOCX 模板
quality/pytest 测试和评测脚本

Agent 构建：模型只是编排器

这里的 依赖注入 很重要：工具拿到 `AgentDeps`，所以 Web、CLI、测试可以共用同一套逻辑。

CODE 
agent = Agent(
    model,
    deps_type=AgentDeps,
    system_prompt=load_system_prompt(deps.paths.root, deps.project_notes),
    model_settings=ModelSettings(request_limit=100),
    capabilities=[ProcessHistory(compact_history)],
)
