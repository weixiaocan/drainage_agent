# 10 — 实施报告模板契约

**What to build:** 排水监测分析人员可以使用内置模板生成报告初稿，也可以上传遵循占位符规范的自定义 DOCX。系统在生成前校验模板，在报告中标识人工补充模块，并保留旧报告版本。

**Blocked by:** 09 — 迁移现有核心分析能力.

**Status:** ready-for-agent

- [ ] 内置模板根据已计算结果稳定生成有效 DOCX 和综合表。
- [ ] 发布模板规范和可修改的示例模板。
- [ ] 自定义模板上传时校验必需占位符并返回可操作错误。
- [ ] 报告数值全部来自确定性分析结果。
- [ ] 空间拓扑关系模块明确标识为人工补充模块。
- [ ] 新报告创建版本，不覆盖既有报告。
- [ ] 任意 DOCX 自由结构生成路径被移除。
