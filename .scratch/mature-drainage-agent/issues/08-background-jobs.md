# 08 — 后台运行耗时分析

**What to build:** 排水监测分析人员可以把耗时分析提交为本地后台作业，在 Web 查看排队、运行步骤、进度、成功和失败状态，并在完成后打开结果。

**Blocked by:** 06 — 建立分析运行模块.

**Status:** ready-for-agent

- [ ] 提交耗时分析后立即返回可查询的作业标识。
- [ ] Web 展示排队、运行、成功和失败状态及可理解的进度。
- [ ] 作业状态持久化到 SQLite，并关联项目、批次、分析请求和结果。
- [ ] 应用重启后未完成作业不会被误报为成功。
- [ ] 本地执行器具有明确的有限并发上限，不依赖外部队列。
- [ ] 至少一个真实分析通过后台作业完成端到端测试。
