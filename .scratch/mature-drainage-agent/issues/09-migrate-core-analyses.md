# 09 — 迁移现有核心分析能力

**Blocked by:** 07 — 将筛选结果确认为分析基线; 08 — 后台运行耗时分析.

**Status:** ready-for-agent

- [ ] 所有冻结的核心分析能力均只读取当前批次标准数据和分析基线。
- [ ] 降雨事件编号、数据覆盖守卫、点位和时间范围行为保持一致。
- [ ] 需要 event_ids 或资料时返回结构化等待输入状态。
- [ ] 产物按项目、批次、分析身份和版本隔离。
- [ ] 现有数值回归测试和 Agent Eval 关键用例继续通过。
