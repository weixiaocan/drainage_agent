# 03 — 创建派生分析批次

**What to build:** 排水监测分析人员可以选择同一监测项目内的多个分析批次，创建保留来源关系的派生分析批次。点位和时间重叠或数值冲突时，系统停止合并并要求工程师选择来源。

**Blocked by:** 02 — 创建隔离的分析批次.

**Status:** ready-for-agent

- [ ] 用户可以选择至少两个来源批次创建派生分析批次。
- [ ] 派生批次记录全部来源批次且不修改来源数据。
- [ ] 无冲突数据可以合并为新的批次输入。
- [ ] 相同点位和时间的重复或数值冲突会阻止合并并显示范围和数量。
- [ ] 工程师明确选择来源后才能完成冲突合并。
