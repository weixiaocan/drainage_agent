# 05 — 复用导入配置和 LLM 映射建议

**What to build:** 排水监测分析人员可以保存一种数据来源的字段与单位导入配置，并在后续同类文件中复用。确定性规则无法识别时，LLM 只提出候选映射，必须经工程师确认后才能生成标准数据。

**Blocked by:** 04 — 导入并确认标准数据.

**Status:** ready-for-agent

- [ ] 用户可以命名、保存、查看和复用导入配置。
- [ ] 导入配置复用后仍展示映射预览和校验结果。
- [ ] 确定性规则优先于 LLM 候选映射。
- [ ] LLM 通过可替换模型接口调用，测试使用固定响应适配器且不产生费用。
- [ ] LLM 建议不会直接修改原始监测数据或绕过工程师确认。
