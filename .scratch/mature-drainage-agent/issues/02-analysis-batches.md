# 02 — 创建隔离的分析批次

**What to build:** 排水监测分析人员可以在当前监测项目中创建、查看和切换分析批次。每个分析批次独立保存输入、标准数据、分析基线、结果、会话和作业状态，新批次不覆盖旧批次。

**Blocked by:** 01 — 创建并切换监测项目.

**Status:** ready-for-agent

- [ ] Web 可以在当前监测项目内创建、列出、查看和切换分析批次。
- [ ] 分析批次必须属于一个监测项目，不能跨项目访问。
- [ ] 新分析批次不复制、合并或覆盖既有批次数据。
- [ ] 不同批次的文件、会话和结果目录相互隔离。
- [ ] 隔离测试同时使用两个项目和多个分析批次。
