# 07 — 将筛选结果确认为分析基线

**What to build:** 排水监测分析人员可以在当前分析批次运行自动筛选，下载并修改筛选结果，再通过 Web 重新上传和确认。确认后的文件成为分析基线，后续分析必须复用它。

**Blocked by:** 06 — 建立分析运行模块.

**Status:** ready-for-agent

- [ ] 自动筛选完成后进入等待确认状态并停止后续分析。
- [ ] Web 展示筛选摘要、剔除原因和下载入口。
- [ ] 修改后的筛选文件可以重新上传并通过结构校验。
- [ ] 确认状态绑定文件内容和筛选参数身份。
- [ ] 确认后继续分析时复用现有文件，不重新执行筛选。
- [ ] 输入或筛选文件变化后，旧分析基线自动失效。
