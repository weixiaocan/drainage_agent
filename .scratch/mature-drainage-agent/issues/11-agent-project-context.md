# 11 — 让 Agent 对话使用项目事实

**What to build:** 排水监测分析人员在当前项目和分析批次中与 Agent 对话。Agent 从持久化项目事实获取资料、分析基线、结果和作业状态，不从聊天历史猜测确定性状态。

**Blocked by:** 07 — 将筛选结果确认为分析基线; 09 — 迁移现有核心分析能力.

**Status:** ready-for-agent

- [ ] 每次对话明确关联当前项目、批次、会话和运行编号。
- [ ] Agent 工具调用不能访问其他项目或批次的数据。
- [ ] 筛选确认、event_ids 和结果新鲜度来自持久化状态。
- [ ] 多轮上下文继续保持点位、时间和旱雨天等用户约束。
- [ ] 修改分析基线、覆盖和删除等操作要求绑定具体目标的明确确认。
- [ ] Web 工作台与对话展示同一项目事实。
