# 04 — 导入并确认标准数据

**What to build:** 排水监测分析人员可以向分析批次上传原始监测数据，查看系统识别的字段、时间、点位、指标和单位，确认或修正映射后生成标准数据。原始监测数据保持不变。

**Blocked by:** 02 — 创建隔离的分析批次.

**Status:** ready-for-agent

- [ ] 上传文件按分析批次保存为不可变的原始监测数据。
- [ ] Web 展示编码、字段、类型、单位、异常和标准数据预览。
- [ ] 确定性规则能够识别现有演示数据和常见列名。
- [ ] 单位缺失、冲突或无法确定时必须等待工程师确认。
- [ ] 确认后生成规范字段和统一单位的标准数据，分析工具不直接读取原始文件。
- [ ] 无效时间、空数据和无法映射的必需字段返回可操作错误。
