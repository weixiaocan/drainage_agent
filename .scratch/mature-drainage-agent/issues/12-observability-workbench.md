# 12 — 建立可观测运行记录页面

**What to build:** 项目维护者可以在 Web 查看一次真实运行的模型、工具步骤、状态、耗时、Token、错误和产物，并从 Eval 关联到对应运行记录。

**Blocked by:** 08 — 后台运行耗时分析; 09 — 迁移现有核心分析能力; 11 — 让 Agent 对话使用项目事实.

**Status:** ready-for-agent

- [ ] 运行轨迹关联项目、批次、会话、运行和作业编号。
- [ ] 记录模型、工具、参数摘要、状态、耗时、Token、错误和产物。
- [ ] Web 可以按项目和批次查看运行列表及单次运行步骤。
- [ ] API 密钥永不记录，完整原始数据和完整对话默认不记录。
- [ ] 用户可以主动开启受控的深度调试模式。
- [ ] Eval 结果能够引用对应运行标识。
