# 06 — 建立分析运行模块

**What to build:** 排水监测分析人员可以在当前分析批次中运行数据质量检查。统一分析运行模块负责前置条件、完整分析身份、结果复用、新版本、产物和工具状态，Web 和 Agent 通过同一个接口获得结果。

**Blocked by:** 04 — 导入并确认标准数据.

**Status:** ready-for-agent

- [ ] 数据质量检查只读取当前批次的标准数据。
- [ ] 分析身份包含输入、分析基线、规范参数和算法版本。
- [ ] 分析身份一致时默认复用结果，明确重跑时创建新版本。
- [ ] 输入或参数变化后不得把旧结果标记为当前结果。
- [ ] Web 与 Agent 使用同一分析运行接口，不重复实现前置条件和落盘规则。
- [ ] 现有数据质量数值与重构前基线一致。
