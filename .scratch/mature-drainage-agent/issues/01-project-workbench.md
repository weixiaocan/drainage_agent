# 01 — 创建并切换监测项目

**What to build:** 排水监测分析人员可以在 Web 工作台创建、查看和切换监测项目。项目元数据保存到 SQLite，每个项目拥有独立且持久化的文件空间，容器或应用重启后仍可读取。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Web 可以创建、列出、查看和切换命名监测项目。
- [ ] 项目元数据保存到 SQLite，项目文件空间相互隔离。
- [ ] 重启应用后，已经创建的项目仍然存在。
- [ ] 两个项目不能读取或下载对方的文件。
- [ ] Web 用户工作流测试使用真实临时 SQLite 和临时文件目录通过。
