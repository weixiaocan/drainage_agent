# Drainage Agent 评测

## 目的

评测用于验证 Drainage Agent 的确定性计算、Web 用户工作流和 Agent 编排质量。运行日志负责记录真实任务经过了哪些步骤；Eval 使用测试场景判断这些步骤和结果是否符合预期。

## 三个验收层

1. **Web 用户工作流**：从创建或选择监测项目开始，覆盖数据导入、映射确认、筛选确认、后台分析、结果查看和报告下载。
2. **确定性分析**：验证数据标准化、筛选、降雨、事件响应、排污规律、RDII、风险和报告组装的数值与产物。
3. **Agent Eval**：验证自然语言理解、工具与参数选择、多轮上下文、人工确认、边界拒绝和报告范围。

## 发布门槛

- 所有确定性单元测试和集成测试通过。
- 关键 Agent Eval 用例全部通过，非关键 Eval 总通过率至少为 90%。
- Docker 能从全新环境启动并完成脱敏演示流程。
- 不存在会导致项目间数据混用、错误报告或文件丢失的严重问题。
- README 能指导陌生用户完成安装和首次分析。

## 运行方式

运行确定性测试：

```powershell
python -m pytest
```

Agent Eval 的用例、运行器、人工标注数据和 HTML 报告位于 `quality/eval/`。需要真实模型调用的完整 Eval 会产生费用，应在发布前手动运行；CI 只运行选定的关键用例。

每个 Eval 回合记录独立的 `run_id`。评测结果可以用该标识定位对应 trace 或项目内 Agent 运行记录，而不需要保存完整提示词和模型回复。
