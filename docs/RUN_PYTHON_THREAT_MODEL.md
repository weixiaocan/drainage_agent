# `run_python` 威胁模型

## 资产与边界

需保护模型密钥、主 SQLite、应用源码、项目和批次隔离数据、宿主文件及 Docker 控制面。可信计算基包括确定性策略、主应用的请求状态机、固定配置的 Sandbox Controller、Docker Engine 和宿主操作系统；模型代码、声明、上传内容和沙箱输出均不可信。

## 主要威胁与控制

| 威胁 | 必要控制 |
|---|---|
| 读取密钥、数据库、源码或其他项目 | 沙箱仅挂载固定任务目录；输入只读；策略拒绝敏感访问 |
| 网络外传 | 沙箱网络固定为 none；策略拒绝网络模块 |
| 命令执行、提权、逃逸 | 非 root、只读根文件系统、drop ALL、no-new-privileges、固定镜像和命令 |
| 资源耗尽 | CPU、内存、PID、时间、临时空间、输出数量和大小上限 |
| 路径、链接和恶意产物 | Controller 根目录约束；接收端拒绝链接和特殊文件并重新解析、命名和哈希 |
| 审批重放或串用 | 审批绑定项目、批次、会话、代码哈希和有效期；事务化单次消费 |
| Agent 绕过审批 | `needs_approval` 由外层代码硬停止；Agent 无审批接口权限 |

## 残余风险

Docker Engine 或宿主内核被攻破、管理员主动放宽挂载或特权设置、修改安全代码后未重新审计、以及模型服务商的数据处理不在本系统承诺范围内。默认仅绑定本机端口，不等同于公网部署安全。
