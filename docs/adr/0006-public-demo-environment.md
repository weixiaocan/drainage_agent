# 公开演示环境

项目需要一个可公开访问的 Demo，用于作品展示和部署验证。Demo 部署在维护者自有的服务器和域名下，使用与自部署相同的 Docker Compose 和核心应用，通过 `DRAINAGE_DEMO_MODE=1` 进入受限模式；不提供 SaaS 或多账户服务。

## Consequences

- 演示模式拒绝上传或替换数据、创建项目、删除、重置工作区、上传模板，以及下载原始数据和全部文件；关闭 FastAPI 接口文档。
- 对话接口按访问 IP 限制每分钟请求数（`DRAINAGE_DEMO_REQUESTS_PER_MINUTE`，默认 3），并限制同时进行的对话数（`DRAINAGE_DEMO_MAX_CONCURRENT_CHATS`，默认 2）。
- 演示模式不提供 `run_python`。执行前的审批由发起请求的用户完成，公开环境中访客会审批自己的请求，审批起不到把关作用；访客代码仍在沙箱内运行，但会占用服务器资源，也增加了暴露面。
- 只能使用脱敏演示数据。服务器地址、密钥和部署凭据不写入仓库。
- 目前由维护者手动部署。主分支自动部署、失败回滚、每日费用预算熔断和定时恢复演示数据尚未实现。
