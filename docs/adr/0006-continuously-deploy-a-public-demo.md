# 主分支持续部署到公开演示环境

正式用户通过开源 Docker 镜像自行部署，但项目还需要展示完整的持续部署能力。因此，主分支通过 CI 和部署门槛后，自动部署到用户自有服务器与域名下的公开 Demo；Demo 仅用于作品展示和部署验证，不提供 SaaS 或多账户服务。

## Consequences

版本标签应发布 GitHub Release 和 Docker 镜像，主分支部署后执行健康检查，失败时停止发布或回滚。公开 Demo 只能使用脱敏演示数据，允许访客真实对话、运行核心分析并生成示例报告，但禁止上传文件、创建永久项目和访问服务器文件。

Demo 使用低成本的已验证模型，并通过结果缓存、请求限流、单次任务上限、每日费用预算与超限熔断控制成本；运行数据定时恢复到干净状态。服务器地址、密钥和部署凭据通过 CI/CD Secrets 管理，不写入仓库。
