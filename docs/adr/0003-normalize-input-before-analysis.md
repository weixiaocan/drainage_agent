# 分析工具只读取经过确认的标准数据

开源工具会接收来自不同系统、字段名称和单位各异的监测文件。系统保留原始监测数据，通过统一导入流程完成编码识别、字段映射、类型转换、单位统一和质量校验；工程师确认后生成标准数据，所有筛选与分析工具只读取标准数据，不能各自解析原始文件。

## Consequences

现有固定列名别名和规范字段继续作为标准化基础，但 Web 需要提供映射预览与确认，并允许保存可复用的导入配置。单位明确时可以自动换算；单位缺失、冲突或无法判断时必须暂停并要求工程师确认，不得根据数值大小猜测单位。

字段映射优先由确定性规则完成。规则无法确定时，LLM 只能根据表头和有限样例提出候选映射，且必须经工程师确认；实际解析、单位换算和校验仍由确定性代码执行。
