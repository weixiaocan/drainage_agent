# 以监测项目作为唯一用户可见工作空间

> 更新：标准数据变化后的旧结果处理方式已由 ADR 0014 改为直接清空；不再标记过期或跨数据版本复用。

用户只需要为一次分析工作指定一个“监测项目”名称。项目名称是工作空间的用户可见名称，不承诺等同于物理目录名：选择已有名称时继续加载其中的数据、结果和对话，使用新名称时创建新的独立工作空间。界面不再要求用户理解或选择“分析批次”。

导入监测数据始终重新识别并替换当前项目的标准数据。标准数据变化后，既有衍生结果会被标记为可能过期；再次分析时仍按完整分析身份判断是否可以复用，数据或参数发生变化则重新计算。

## Consequences

- 创建或选择项目时，系统自动选择一个内部工作空间，用户无需参与。
- 旧项目继续使用其最近的既有工作空间，以保留历史数据和结果。
- 数据库和兼容 API 暂时保留内部批次标识，避免破坏已有持久化数据和调用方，但该概念不再出现在主界面。
- 同名项目由界面解释为加载已有项目，不创建重复工作空间。
